# Hema Uni — هيما الجامعي

مساعد دراسي عربي لطلاب جامعة الأزهر بغزة. نسخة تجريبية مستقلة: ارفع PDF، اقرأ النص المستخرج، اسأل المدرّس الذكي، لخّص المحاضرة، وأنشئ اختبارًا قصيرًا.

## الميزات الحالية

- واجهة عربية RTL متجاوبة للهاتف والكمبيوتر.
- رفع PDF واستخراج نص كل صفحة عبر PDF.js.
- تخزين المحاضرات والاختبارات محليًا في IndexedDB.
- مساعد AI عبر Cloudflare Pages Function؛ مفتاح Gemini لا يصل إلى المتصفح.
- إجابات وتلخيصات واختبارات مولّدة من المقاطع المختارة من المحاضرة.
- إحالات للصفحات مع إمكانية الانتقال إلى النص المرجعي.
- صفحة مكتبة واختبارات محفوظة، وحذف محاضرة مع اختبارات مرتبطة.
- PWA قابلة للتثبيت، مع إصدار Android عبر Capacitor.
- رسائل خطأ واضحة عند غياب إعداد AI أو نفاد الحصة أو تعذّر قراءة PDF.

## المتطلبات

- Node.js 22 أو أحدث.
- npm.
- لتطوير Android: Android Studio وAndroid SDK وJDK 21.

## التشغيل المحلي

~~~bash
npm install
npm run dev
~~~

لفحص TypeScript وبناء نسخة الويب:

~~~bash
npm run check
npm run build
npm run preview
~~~

## تفعيل المساعد الذكي

يستخدم الخادم الوسيط functions/api/ai.ts مزود Gemini. لا تضف المفتاح إلى متغيرات VITE ولا تحفظه داخل التطبيق.

في Cloudflare Pages، أضف السر التالي إلى إعدادات المشروع (Settings → Variables and Secrets):

- GEMINI_API_KEY: مفتاح API الخاص بك.
- GEMINI_MODEL: اختياري؛ الافتراضي gemini-2.5-flash.

بعدها أعد النشر. استخدام API يخضع لحصص وشروط مزود الخدمة؛ لا يوجد ضمان أن توليد AI مجاني بلا حدود. عند عدم ضبط المفتاح، سيعرض التطبيق رسالة توضح أن AI غير مفعّل، بينما تبقى المكتبة المحلية متاحة.

## نشر الويب على Cloudflare Pages

1. اربط مستودع GitHub بـ Cloudflare Pages.
2. Build command: npm run build.
3. Build output directory: dist.
4. أضف GEMINI_API_KEY من لوحة الأسرار، وليس داخل ملفات Git.
5. أعد النشر واختبر /api/ai من التطبيق.

يوجد wrangler.toml للإعداد الأساسي. لا يتطلب تخزين المواد محليًا قاعدة بيانات سحابية.

## بناء Android APK

محليًا بعد إعداد Android Studio:

~~~bash
npm run build
npx cap add android
npx cap sync android
npx cap open android
~~~

من Android Studio اختر Build → Build APK(s)، أو نفّذ من مجلد android:

~~~bash
./gradlew assembleDebug
~~~

ملف APK التجريبي يظهر عادة في:

~~~text
android/app/build/outputs/apk/debug/app-debug.apk
~~~

يوجد سير عمل GitHub Actions لبناء الويب وتجربة بناء APK عند كل push إلى main. حمّل الملفات الناتجة من تبويب Actions → Workflow run → Artifacts. هذا APK تجريبي Debug، وليس إصدارًا موقّعًا للنشر على متجر.

## حدود معروفة

- الإصدار الحالي يدعم PDF ذي النص القابل للاستخراج. PDF الممسوح ضوئيًا قد يحتاج OCR غير مضمّن هنا.
- لا يعمل توليد إجابات جديدة دون اتصال؛ الملفات والنتائج المحفوظة تبقى محليًا.
- البحث في النسخة الحالية يعتمد مطابقة كلمات بسيطة، وليس فهرسًا دلاليًا.
- يُرسل مقتطف النص المختار إلى مزود AI فقط عند طلب المساعدة. يجب إبلاغ المستخدم بذلك وعدم رفع محتوى لا يملك حق مشاركته.
- المراجع الصفحية يتم التحقق من أرقامها مقابل الصفحات المرسلة، لكن يجب مراجعة دقة الإجابة يدويًا قبل الاعتماد عليها دراسيًا.
- المشروع مبادرة طلابية مستقلة، وليس منصة رسمية أو تابعة لجامعة الأزهر.
