# Hema Uni — هيما الجامعي

مساعد دراسي عربي مستقل لطلاب جامعة الأزهر بغزة. ارفع محاضرة PDF، اقرأ صفحاتها، اسأل مدرس AI، أنشئ امتحانًا مؤقتًا، وحوّل المفاهيم إلى بطاقات مراجعة.

## الميزات

- واجهة عربية RTL متجاوبة، شريط تنقل سفلي للهاتف، إعدادات خط، وPWA قابلة للتثبيت.
- رفع PDF وحفظه محليًا في IndexedDB، مع استخراج النص حسب رقم الصفحة.
- قارئ PDF مرئي: انتقال بين الصفحات، تكبير وتصغير، ورسم تدريجي للصفحات.
- مدرس AI للشرح والتلخيص، شرح نص محدد، وإجابات مبنية على مقتطفات المحاضرة مع إحالات إلى صفحات المصدر.
- امتحانات مولّدة من المحاضرة: 5/10/15 سؤالًا، صعوبة سهلة/متوسطة/صعبة، مؤقت اختياري، سؤال منفرد أو عرض شامل، تصحيح تلقائي ومراجعة الأخطاء.
- بطاقات حفظ يولّدها AI، قلب البطاقة، وتذكير مراجعة متباعدة يدوي: مراجعة بعد 10 دقائق أو بعد يوم ثم مضاعفة الفاصل حتى 30 يومًا.
- دفتر ملاحظات محلي لحفظ مقتطفات مهمة وربطها باسم المحاضرة ورقم الصفحة.
- إملاء صوتي للأسئلة عند دعم المتصفح Web Speech API.
- ملفات المحاضرات والاختبارات والبطاقات والملاحظات محفوظة محليًا؛ لا حاجة لحساب طالب في الإصدار الأول.
- Cloudflare Pages Function تتصل بـ Gemini server-side، فلا ينكشف مفتاح API في الواجهة أو APK.
- GitHub Actions يبني نسخة الويب ويحاول إنشاء Android debug APK كـ Artifact.

## المتطلبات

- Node.js 22 أو أحدث.
- npm.
- لبناء Android محليًا: Android Studio وAndroid SDK وJDK 21.

## التشغيل المحلي

~~~bash
npm install
npm run dev
~~~

فحص TypeScript وبناء الموقع:

~~~bash
npm run check
npm run build
npm run preview
~~~

## إعداد Gemini API

1. أنشئ API key من Google AI Studio.
2. في إعدادات Cloudflare Pages، أضف GEMINI_API_KEY كـ Secret.
3. اختياريًا أضف GEMINI_MODEL. الافتراضي في الخادم gemini-2.5-flash.
4. أعد النشر ثم اختبر شرح ملف PDF.

لا تضف المفتاح إلى متغيرات VITE أو إلى ملف متعقّب في Git. يرسل التطبيق مقتطفات الصفحات الضرورية فقط عند طلب AI. راجع شروط مزود AI وحصصه وحدوده؛ لا يوجد ضمان لاستخدام مجاني غير محدود.

## نشر الويب

- اربط المستودع بـ Cloudflare Pages.
- Build command: npm run build
- Build output directory: dist
- أضف GEMINI_API_KEY من لوحة Secrets ثم أعد النشر.
- لا يحتاج الإصدار الحالي إلى DB سحابية أو تخزين ملفات مركزي.

ملف الخادم الوسيط: functions/api/ai.ts. ملف إعداد Pages: wrangler.toml.

## بناء APK محليًا

~~~bash
npm run build
npx cap add android
npx cap sync android
npx cap open android
~~~

في Android Studio اختر Build → Build APK(s)، أو من مجلد android:

~~~bash
./gradlew assembleDebug
~~~

المسار المعتاد:

~~~text
android/app/build/outputs/apk/debug/app-debug.apk
~~~

## الحصول على APK من GitHub

افتح Actions → آخر تشغيل لـ Hema Uni CI → Artifacts، ونزّل hema-uni-android-debug-apk. هذا APK تجريبي Debug وليس تطبيقًا موقّعًا للنشر في المتجر. إذا فشل البناء، افتح سجل الـ job لمعرفة الخطأ الحقيقي.

## حدود النسخة الحالية

- PDF الممسوح ضوئيًا الذي لا يحتوي نصًا قابلًا للاستخراج يحتاج OCR، غير مضمّن في النسخة الحالية.
- AI يحتاج اتصالًا. فتح الملفات والنتائج المحفوظة متاح محليًا، لكن إنشاء شرح أو اختبار جديد لا يعمل دون إنترنت.
- البحث داخل الصفحات يعتمد مطابقة كلمات بسيطة، وليس فهرسًا دلاليًا كاملًا.
- الإملاء الصوتي يعتمد على دعم المتصفح وقيود الأذونات والاتصال.
- أرقام الصفحات تُفلتر مقابل الصفحات المرسلة، لكن يجب التحقق يدويًا من دقة إجابات AI قبل الاعتماد الأكاديمي.
- لا توجد مزامنة بين الأجهزة أو حسابات طلاب في هذا الإصدار. مسح بيانات المتصفح/التطبيق قد يحذف المواد المحلية.
- المشروع مبادرة طلابية مستقلة، وليس منصة رسمية أو تابعة لجامعة الأزهر. استخدم مواد تملك حق استخدامها.

## هيكل المشروع

~~~text

  App.tsx                واجهات التطبيق والامتحانات والبطاقات والملاحظات

  lib/ai.ts              العميل الذي يرسل مقتطفات المحاضرات
  lib/storage.ts         IndexedDB محلي
  styles.css             تصميم RTL متجاوب
functions/api/ai.ts      وسيط Gemini server-side
public/icons/icon.svg    أيقونة PWA

~~~

## الخصوصية

الملفات محفوظة محليًا في IndexedDB. عند طلب AI، يرسل التطبيق المقاطع التي اختارها إلى وظيفة الخادم، ومنها إلى مزود AI. لا ترفع محتوى حساسًا أو محاضرات لا تملك صلاحية مشاركتها. لا تضع مفاتيح سرية في المستودع.
